SunSathiyAI - run locally (needs Node.js 20+; no npm install required)

1. Open a terminal in this folder
2. node server.mjs
3. Open http://localhost:3000

The Gnani API key lives in the .env file (server side only). Do not double-click the
HTML file: voice needs the server above. Don't commit or share .env.
Optional settings in .env: GNANI_TTS_VOICE, GNANI_TTS_MODEL, PORT.
